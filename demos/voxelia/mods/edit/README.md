# Mod « edit » — édition de structures

Outils (clic droit ; accroupi pour l'action secondaire), à obtenir avec `/edit tools` :

| Outil | Clic droit | Accroupi |
| --- | --- | --- |
| Baguette de sélection | premier coin, puis second | efface la sélection |
| Copier | copie la zone | coupe |
| Coller | colle contre le bloc visé (aperçu bleu) | rotation, miroir, fusion |
| Déplacer | amène la zone contre le bloc visé | |
| Remplir | plein, creux, murs, arêtes, air seulement | |
| Effacer | vide la zone | |
| Remplacer | un bloc (ou tous) par un autre | |
| Annuler | annule | rétablit |
| Formes | ligne, cercle, ellipse, rectangle, parallélépipède, sphère, ellipsoïde, cylindre, cône, pyramide, dôme, tore | |
| Formule | relation f(x, y, z), courbe, surface ou solide paramétrés (comme mathplot) | |
| Bibliothèque | enregistrer, charger, supprimer, exporter, importer | |

Commande : `/edit help`. Structures du monde : `<sauvegarde>/structures` ;
échange entre mondes : `data/voxelia/structures` (option `--structures`).
Formats : `.vxs.json` (natif), `.json` (structure de mod), `.we` (WorldEdit),
`.mts` (Minetest). Limites (taille de la zone copiable, d'une forme) : réglages
du mod, par monde.
