## 5. Conseils pour obtenir un bon résultat dans ton jeu

- **Murs :** utilise les prompts 1 et 2 pour les couloirs, et le prompt 3 pour certaines zones de service.
- **Sol :** utilise le prompt 4 pour les couloirs relativement propres et le prompt 6 pour les zones abandonnées.
- **Plafond :** utilise le prompt 7 pour un plafond enduit ou le prompt 8 pour un faux plafond à dalles.
- **Portes :** choisis une couleur principale pour l’hôpital, puis réserve le rouge aux portes coupe-feu que tu veux rendre facilement reconnaissables.
